# Mila_sladco — Витрина кондитерской & Мультиссылка (Taplink)

Интерактивный мобильный прототип сайта-витрины и страницы-мультиссылки для авторской кондитерской **Mila_sladco** (Москва, кондитер Люда).

---

## 🎯 Реализованные возможности

1. **Экран 1: Мультиссылка (Taplink-режим)**
   - Шапка кондитера: аватар Люды с индикатором онлайн-статуса, дескриптор бренда, бейджи доверия (100% ручная работа, натуральный шоколад Callebaut, бережная доставка).
   - Кнопка связи в **MAX** (`https://max.ru/mila_sladco`) — быстрый ответ кондитера в чате.
   - Кнопка перехода в **Telegram-канал** (`https://t.me/mila_sladco_cakes`) — новинки, анонсы и закулисье.
   - Кнопка **«Каталог десертов»** — плавное переключение на интерактивную витрину.
   - Кнопка **«Срочный заказ / Позвонить»** — прямой набор номера для экстренных заказов день в день.
   - Горизонтальная карусель **«Хиты этой недели»** — быстрое знакомство с бестселлерами прямо с главного экрана.

2. **Экран 2: Витрина корпусных десертов**
   - Интерактивные фильтры по категориям: *Все десерты*, *Корпусные пирожные*, *Наборы в коробках*, *Бенто-торты*.
   - Карточки товаров: реалистичные фотографии в высоком разрешении, граммовка, бейджи («Хит продаж», «Бестселлер», «Новинка»), краткое описание вкуса, кнопка быстрого добавления `+`.
   - **Детальная карточка десерта (Bottom Sheet)**:
     - Описание вкусовых нюансов и текстуры;
     - Полный разбор слоев (глянцевая зеркальная глазурь, мусс, ягодное кули, сабле);
     - Таблица КБЖУ на 100 г (калории, белки, жиры, углеводы);
     - 100% натуральный состав и условия хранения (72 часа при +2..+6°C);
     - Счетчик порций и кнопка добавления в корзину.

3. **Экран 3: Корзина и Оформление без сложного бэкенда**
   - Плавающая плашка корзины снизу экрана (Floating Bar) с анимацией появления, счетчиком позиций и суммой.
   - Модальное окно заказа: список товаров с возможностью изменить количество или удалить.
   - Форма данных:
     - Имя клиента;
     - Телефон или никнейм (@username);
     - Выбор канала отправки заказа: **MAX** или **Telegram**;
     - Желаемая дата и удобный временной интервал;
     - Способ получения: курьерская доставка по Москве или самовывоз (м. Раменки);
     - Пожелания к оформлению (надпись на торте, поздравительная открытка).
   - **Генерация структурированного заказа**: при нажатии формируется аккуратный чек с эмодзи и открывается диалог с кондитером в выбранном мессенджере (с автоматическим резервным копированием в буфер обмена).

## 🚀 Как запустить локально

Для запуска не требуются сборщики (Webpack, Vite и др.) — проект работает сразу в любом современном браузере.

### Вариант 1 (Python)
```bash
python3 -m http.server 8080
```
Затем открыть: `http://localhost:8080`

### Вариант 2 (Node.js)
```bash
npx serve .
```

### Вариант 3
Просто открыть файл `index.html` двойным кликом в браузере Safari, Chrome или Edge.

## 🌐 Развертывание в сети (Бесплатный хостинг)

- **GitHub Pages**: В настройках репозитория в разделе *Pages* выбрать ветку `main` и корневую папку `/ (root)`. Сайт станет доступен через 1 минуту по адресу `https://<username>.github.io/mila-sladco/`.
- **Vercel / Netlify**: Подключить репозиторий и нажать *Deploy* (настройки по умолчанию).
