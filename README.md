# Mila_sladco — Витрина кондитерской & Мультиссылка

Проект сайта-витрины и страницы-мультиссылки для кондитерской **Mila_sladco** (Москва).

---

## 🎯 Цели проекта

1. **Мультиссылка (Taplink-альтернатива) для соцсетей:**
   - Быстрый переход в Telegram-канал кондитерской.
   - Прямая кнопка связи в мессенджере MAX.
   - Ссылка на витрину десертов и оформление заказа.

2. **Сайт-витрина (Каталог десертов):**
   - Фокус на авторские корпусные пирожные (и торты).
   - Витрина: фото десертов, названия, вкусы, цены.
   - Детальная карточка пирожного (разрез, начинка, состав, вес).
   - Корзина и оформление заказа с отправкой заявки прямо в мессенджер (MAX / Telegram) кондитеру.

---

## 🛠 Стек технологий

- Современный легкий веб-стек (HTML5 / Tailwind CSS / Vanilla JS или React/Vite).
- Адаптивный мобильный дизайн (Mobile-First, так как 95% заказов приходят из соцсетей с телефонов).
- Развертывание: бесплатный хостинг (GitHub Pages / Vercel).
