Задача — создать максимально простой, эстетичный и автономный мобильный сайт (Mobile-First Taplink + интерактивная витрина десертов), синхронизированный с облачной базой на GitHub:

## 3. Облачная синхронизация с базой данных GitHub (`js/sync-service.js`)

1. **Файлы базы данных в репозитории:**
   - `data/catalog.json` — актуальный каталог десертов
   - `data/profile.json` — настройки профиля, статус и контакты
2. **Как работает чтение для покупателей:**
   - При входе на сайт сначала моментально отрисовывается локальный кэш (0 мс задержки).
   - В фоне `SyncService.pullFromRemote()` проверяет свежие данные:
     - 1-й приоритет: GitHub API (`api.github.com/repos/stanlyu/mila-sladco/contents/data/...`)
     - 2-й приоритет: `raw.githubusercontent.com/...` с анти-кэш query параметром
     - 3-й приоритет: статический `data/*.json` с хостинга
   - При обнаружении обновлений витрина мягко перерисовывается.
3. **Как работает запись из кабинета кондитера:**
   - В кабинете Люды появилась карточка **«База данных GitHub»** со статусом и кнопками.
   - Любое изменение (смена цены, тумблер наличия, добавление десерта, смена контактов) при наличии сохраненного токена автоматически отправляет коммит в репозиторий через GitHub REST API!
   - Токен настраивается 1 раз в модальном окне «Настройки базы» (Fine-Grained Personal Access Token с правами на запись содержимого репозитория).
4. **Сжатие фотографий на клиенте:**
   - Перед отправкой фото с камеры смартфона (обычно 8-15 МБ) автоматически сжимаются на Canvas до 900px и качества JPEG 82% (~70-120 КБ), что исключает раздувание репозитория и ускоряет работу.
